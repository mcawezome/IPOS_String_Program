# String Number Value

Student project · North Metropolitan TAFE · August 2024 · pair project with a classmate

A Python class, `StringNumValue`, that gives any string a numeric value: letters score 1–26 (`a`/`A` = 1 … `z`/`Z` = 26), digits keep their value, other characters score 0, and a string's value is the sum of its characters. The exercise was about writing well-documented classes and unit tests.

## Running the tests

```bash
python3 -m unittest test/test_string_num_value.py
```
